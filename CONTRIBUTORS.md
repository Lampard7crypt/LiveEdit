# Hacktoberfest 2026 Hall of Fame

Thank you to everyone who helped build LiveEdit this October. Every merged pull request earns a badge.

## The badges

| Badge | How to earn it |
| --- | --- |
| <img src=".github/badges/first-pr.svg" width="220" alt="First PR Merged"> | Get your first PR merged. Awarded automatically. |
| <img src=".github/badges/test-hero.svg" width="220" alt="Test Hero"> | Add or improve tests (backend `pytest` or frontend Jest). |
| <img src=".github/badges/bug-squasher.svg" width="220" alt="Bug Squasher"> | Fix a real bug. |
| <img src=".github/badges/docs-champion.svg" width="220" alt="Docs Champion"> | Improve docs, guides or setup instructions. |
| <img src=".github/badges/pixel-perfect.svg" width="220" alt="Pixel Perfect"> | Polish the UI: design, accessibility, empty/loading/error states. |
| <img src=".github/badges/audio-alchemist.svg" width="220" alt="Audio Alchemist"> | Add or improve audio effects. |
| <img src=".github/badges/contributor.svg" width="220" alt="Hacktoberfest contributor"> | Any merged PR. Awarded automatically. |

When your PR is merged, a bot comments with your badges and a snippet to paste into your GitHub profile.
